# Diplomski rad
Cilj rada je implementirati ili dodatno trenirati postojeću duboku neuronsku mrežu za segmentaciju i detekciju grana koristeći fuziju podataka o boji (RGB) i dubini (D). Ključni zadatak je osposobiti model za precizno razlikovanje grana od debla te za klasifikaciju ostalih objekata, poput potpornih stupova i žica, kao pozadinskog šuma.
